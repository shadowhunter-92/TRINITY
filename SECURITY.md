# Security policy

TRINITY v0.1.x is experimental research code and **not production-ready** or certified for
industrial control, medical, safety-critical, or other regulated environments.

Please read [`docs/SECURITY.md`](docs/SECURITY.md) for the threat model, networking gates,
protocol limitations and risk register.

## Report a vulnerability privately

Prefer GitHub's **Private vulnerability reporting** on this repository's Security tab
if the repository owner has enabled it. If that option is not available, contact the
maintainer through an agreed private channel before disclosing vulnerability details.
Do **not** publish an exploit or credential in a public issue or pull request.

No fixed response-time or patch SLA is offered for this laboratory release.

## Supported versions

| Version | Support level |
| --- | --- |
| `main` | Best-effort research maintenance |
| v0.1.x | Best-effort; no production support commitment |
